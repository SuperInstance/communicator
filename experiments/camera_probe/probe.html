camera exposure probe — one camera, five constraint sets, numbers

Presets P0–P4 apply a constraint set to the same camera. The luma is the mean of the 160×96 data frame, computed exactly as the takes compute it. Sliders are built from getCapabilities() and applied live. LOG PRESET samples 3 s and writes a line to results.jsonl.

the data canvas — 160×96, what the pipeline sees

presets

Pick a preset. The first request asks for camera permission; after that the device is pinned so every preset measures the SAME camera.

log a measurement

Samples the luma for 3 s, then POSTs the preset, the track's getSettings(), a capabilities summary and the luma mean/min/max to the probe server, which appends to experiments/camera_probe/results.jsonl. If any slider has been moved, the record is logged as P-manual and carries the slider values as numbers.
