## Lane A — scientific frontier (priority order)

**H1. Is the dissociation a pooling artifact? (RUN FIRST — adjudicates
the most-cited finding, 0 API calls.)** Whole-line intent×RMS was
+0.038; test 10 a-priori sub-line windows (start 300ms, energy peak,
final 300ms, final-syllable lengthening, final F0 slope...). If any
family reaches rho≥0.30 with BH correction + split-half confirmation,
the layers couple at the right timescale; if none, the dissociation is
definitive at every granularity. Artifacts: /tmp/e7/ (cached verdicts +
audio16k). 30–60 min.

**H2. Post-line rest carries judged intent.** Do high-intent lines get
longer/more-probable aftermath rests (Jonckheere across intent
quartiles, partialing line duration + scene position)? Meaning in the
timing BETWEEN events — the band analogy's literal test. 0 API calls.

**H3. Presence-gate evidence-accumulation curve (the boldest new
measurement).** Gate CC vs utterance prefix length (0.25/0.5/0.75/1.0,
word-boundary cuts); t50 ≤ 0.7 of the line enables pre-endpoint scored
intent — the judged modality's own T-minus number. ~800 Jev calls,
10 min. Controls: shuffled prefixes (curve must flatten), garbage with
context (must still park).

**H4. The untested half of the swing: pre-event REST beats rise.** A
rest event in [t−1.5, t−0.2] predicting high-intent lines (AUC ≥ 0.65,
beating the 4s rise gradient). If rests win, endpointing is purely
acoustic. Stage 1 zero-cost on cached artifacts.

**H5. Conformal sets over the provider matrix converge with per-item
stability.** 90% coverage with median set ≤2/5 levels on the
by-construction corpus; set size vs Jev resample spread (rho ≤ −0.4).
Implements the §14 ceiling claim; divergence would be a NEW distinction
(within-model jitter ≠ between-model disagreement).

**H6. Measured-only question detection near the published 0.88
ceiling.** Logistic on final-window features (source-text punctuation
labels, never whisper's); start-window control must stay at chance.
Either the measured half already encodes the speech act, or the typed
layer's necessity is demonstrated — informative both ways.

**H7. F0 register-shift events predict judged ADDRESSEE changes.**
≥3-semitone phrase-median jumps across rests (the JFK artifact class,
formalized) as cheap turn detectors scheduling the expensive judged
call AT the turn. Register-confound becomes mechanism if it still
predicts addressee.

**H8. Local-model entropy predicts Jev instability — trust for free.**
Ollaya entropy / tev1 |p−0.5| predicting Jev INTENTION spread (CV
rho ≥ 0.5, partialing length). Fading-before-spending at zero marginal
cost. ~300 Jev + 2000 free local asks.

**H9. Measured context lifts the TIMBRE gate (score-first routing).**
Per-line acoustic summary in the judged call's context — does the gate
accept real evidence (gate ≥30 on ≥50% of lines) vs confabulate
(shuffled-context control must fail)? The two layers composed = the
architecture's thesis in miniature.

**H10. E5's machine half: rendered reductions preserve structure.**
Numpy-synth render → re-run DSP → F0 within 1 semitone, rests ≤10ms,
tempo r ≥ 0.8, both speaker clusters, genre accuracy within 5 points.
Cheapest disconfirmation of the whole rendering line; localizes loss
per track.
